# Loyalty App

React Native loyalty challenge built with Expo SDK 54 and TypeScript.

## Run locally

```bash
npm install
npm start
```

Use the Expo CLI prompt to open the app on Android, iOS, or web.

## Configuration

The challenge API URL and client ID are stored in the committed `.env` file. Use `.env.local` to
override them on your machine without changing the shared configuration.

`EXPO_PUBLIC_` variables are included in the application bundle. Never put passwords, access
tokens, or other secrets in them.
